# emoji-accents

Эмодзи-акценты поверх видео: pop-in (0.27с ease-out-cubic, scale 0.3→1.0) → hold → fade-out (0.3с). Полнокадровый qtrle MOV с альфой → EDL `overlays` с `position:"topleft"`. Субтитры рисуются ПОВЕРХ (Hard Rule #1 сохраняется).

## Workflow

1. **Отобрать моменты по транскрипту.** Кандидаты — слова-обозначения и указательные жесты:
   - перечисления сущностей («один — юрист, второй — адвокат» → ⚖ + 🛡 стеком)
   - события («пришёл иск» → 📩), результаты («сверили» → ✅), объекты («суд» → 🏛)
   - направления («внизу» → 👇, «в шапке профиля» → 👆), CTA («напишите» → 💬)

   Плотность: ~1 эмодзи на 8-12с ролика. Не дублировать соседние, не ставить два НОВЫХ одновременно (parallel-reveal запрещён SKILL.md; пара допустима при последовательном появлении — второй через ≥1с).

2. **Предложить список пользователю** (слово → эмодзи → тайминг) до рендера.

3. **Только одиночные codepoint'ы.** PIL не собирает ZWJ-секвенции (👨‍⚖️ развалится): вместо них ⚖, 🛡, 📩, ✅, 🗂, 🏛, 👇, 👆, 💬, 🚀, 🔥, 💰. Хелпер сам упадёт с понятной ошибкой на пустом глифе.

4. **Посчитать payoff-тайминг в output-времени.** Word-timestamps — в SOURCE-времени; overlays — в OUTPUT. Маппинг по логу render.py (пост-snap сегменты): `start_in_output = cum_start(seg) + (word.start − seg.src_start)`. Старт эмодзи на ~0.1с раньше слова.

5. **Рендер клипов:**
   ```bash
   python helpers/emoji_overlay.py "⚖" --duration 2.2 --center 850,520 \
       --out <edit>/animations/emoji/weights.mov
   ```
   - face-биты: `--center 850,430..775` (справа от головы, вертикальный стек для пар), `--size 200`
   - screen-биты: `--center 540,350` (верх-центр), `--size 220`
   - клип обрывается монтажным резом → `--no-fade-out` и длительность до реза

6. **Вписать в EDL** (пути относительно `edit/`):
   ```json
   {"file": "animations/emoji/weights.mov", "start_in_output": 25.20,
    "duration": 5.40, "position": "topleft"}
   ```

7. **Проверка кадрами**: после рендера извлечь кадр на каждом эмодзи-моменте и посмотреть — позиция не конфликтует с лицом/сабами, тайминг совпадает со словом (сверить по burned-in субтитру).

## Позиционирование (1080×1920)

| Зона | center | Когда |
|---|---|---|
| Справа от головы | `850, 430-775` | talking-head, спикер слева |
| Верх-центр | `540, 350` | камера на экран / скринкаст |
| Стек-пара | `850,520` + `850,775` | два связанных эмодзи (⚖+🛡) |

Низ кадра (y > 1400) занят субтитрами — туда не ставить.
