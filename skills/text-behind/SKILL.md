# text-behind

Слово стоит между фоном и человеком: часть букв закрыта головой или плечами, остальное читается. Работает лучше всего там, где вокруг головы есть фон — окно, небо, стена, улица. На кадре «лицо на весь экран» приёму негде развернуться.

## Когда применять

- Хук-слово или слово-тема бита (1 слово, реже 2–3), 1–3 секунды.
- Цифра-панч («500 000», «58 млн €») вместо счётчика.
- Замена скучного статичного кадра, когда вставки нет, а картинка «унылая».

Не применять: под субтитры всей речи (они остаются мелкими по профилю), больше одного текста за спиной одновременно, на кадрах с руками у лица (маска дрожит).

## Workflow

1. **Проверить маску на стопкадре.** Вырезать кадр из середины окна и посмотреть результат:
   ```bash
   python helpers/text_behind.py still --frame <edit>/style/frame.png \
       --text "СОСТОЯНИЕ" --size 190 --pos 540,760 --out <edit>/style/behind_check.png --mask-out <edit>/style/mask.png
   ```
   Смотреть: край маски у кепки и бороды, нет ли «дыр» в футболке. Если рвано — `--feather 5`, порог внутри `PersonMask` (0.35/0.75).
2. **Согласовать слово, шрифт, цвет, место** с пользователем по профилю стиля (`docs/style_profiles/`). По умолчанию: Mont Light, белый 88 %, центр по X, Y на уровне глаз-лба (600–800), размер 160–200 px, трекинг 6–10.
3. **Собрать клип** ровно на окно бита с той же геометрией, что у range в EDL:
   ```bash
   python helpers/text_behind.py clip --video <источник> --start 63.60 --duration 3.00 \
       --text "СОСТОЯНИЕ" --size 190 --pos 540,760 --tracking 8 \
       --vf "<filter из range, если есть>" --out <edit>/animations/behind_state.mov
   ```
   На выходе qtrle MOV с альфой: текст там, где его не закрывает человек, плюс вырезанный человек в зоне текста. Вход — fade 0.25 с и подъём на 24 px, выход — fade.
4. **Вписать в EDL** как обычный overlay, `start_in_output` по пост-snap таймлайну:
   ```json
   {"file": "animations/behind_state.mov", "start_in_output": 63.60, "duration": 3.0,
    "position": "topleft", "comment": "текст за спиной: СОСТОЯНИЕ"}
   ```
   Субтитры не глушить: они мелкие и лежат на футболке, конфликта нет. Если слово за спиной дублирует субтитр — оставить только одно.
5. **Проверить кадрами** три точки: вход, середина, выход. Смотреть швы по контуру головы при движении.

## Правила

- Один текст за спиной за раз, ≥1 с удержания, вход и выход всегда с анимацией.
- Цвет: белый или акцент профиля; чёрный только на светлом фоне без человека в тёмном.
- Слой человека в клипе ограничен зоной текста (+60 px), чтобы рассинхрон с базой в 1 кадр не был виден по всему силуэту.
- Маска считается на CPU, 20–40 мс на кадр; клип на 3 с — секунды.
- Хардкод-пути к шрифтам запрещены в новых вызовах: путь брать из профиля стиля.
