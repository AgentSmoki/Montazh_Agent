# reels-first-frame

Первый кадр решает, остановится ли зритель. Он работает как обложка: по нему сразу понятно, о чём ролик, и он же стоит в сетке профиля рядом с другими роликами серии.

Два правила ролика:
- **кадр показывает тему буквально** — предмет в руках, место, действие, о котором идёт речь;
- **заголовок читается за секунду** — 3–6 слов, крупно, одно слово акцентным цветом.

## Workflow

1. **Выбрать кадр.** Первый бит EDL или отдельный дубль. Годится кадр, где лицо целиком, фон спокойный и есть свободная зона под текст. Кадр, где лицо срезано краем, спасают размытая база и карточка поверх (как в `build_02_4499.py` партии NeuroBRO).

2. **Проверить, что кадр читается.** Вырезать кадр и спросить у vision-MCP, что на нём видно:
   ```bash
   ffmpeg -y -ss 0.4 -i <video> -frames:v 1 -vf scale=720:-2 <edit>/style/first_frame.jpg
   ```
   затем `mcp__teletranscribe__describe_image` с промптом «опиши в 12 словах, что происходит на кадре». Если описание расходится с темой ролика — берём другой кадр или добавляем предмет в руки.

3. **Написать заголовок.** 3–6 слов, обещание или вопрос по теме ролика; одно слово несёт смысл и красится акцентом. Заголовок повторяет обещание хука, не пересказывая его дословно.

4. **Собрать PNG** (шрифт берётся через `platform_paths`, без хардкод-путей — Hard Rule 20):
   ```python
   from PIL import Image, ImageDraw, ImageFont
   import sys; sys.path.insert(0, "helpers")
   import platform_paths as pp

   W, H = 1080, 1920
   font = ImageFont.truetype(pp.find_bold_sans(), 112)
   img = Image.new("RGBA", (W, H), (0, 0, 0, 0))
   d = ImageDraw.Draw(img)
   # строки по 1–3 слова, межстрочный 1.06, тень 4 px
   ```
   Ориентиры: кегль 96–130 px при 1080×1920, капс, межстрочный интервал 1,05–1,1, мягкая тень вместо обводки, акцентное слово — цветом профиля.

5. **Положить в EDL** как overlay на первый бит:
   ```json
   {"file": "animations/cover_title.png", "start_in_output": 0.0, "duration": 3.2,
    "position": "topleft", "comment": "заголовок-обложка"}
   ```
   Вход — подъём на 24 px и fade 0,25 с; выход — fade. Держится, пока звучит хук.

6. **Проверить кадрами.** `helpers/verify_sheets.py` или один кадр на 0,5 с: текст целиком в кадре, лицо не перекрыто, в сетке профиля читается на маленьком превью.

## Safe-zone вертикали 1080×1920

| Зона | Что там | Вывод |
|---|---|---|
| Верх, до ~220 px | шапка площадки, время, кнопки | Заголовок ниже этой линии |
| Низ, ~25–30 % высоты | подпись, ник, музыка, кнопки | Текст выше, субтитры по профилю |
| Правый край | колонка реакций | Отступ от края не меньше 120 px |

## Единство серии

Решения обложки живут в `docs/style_profiles/<клиент>.md`: шрифт, кегль, цвет акцента, высота блока, наличие подложки. Один вид на серию даёт узнавание в сетке профиля и подписку: зритель проверяет, есть ли ещё такое же.

## Правила

- Заголовок повторяет тему ролика и остаётся честным: обещание в кадре и содержание ролика совпадают.
- Одно акцентное слово на заголовок.
- Текст поверх лица не ставим; при нехватке места уменьшаем кегль или переносим блок в свободную зону.
- Для генеративных обложек и карточек на размытой базе — те же правила кегля и safe-zone.
