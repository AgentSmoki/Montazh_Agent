# reels-breakdown

Превращает готовое видео в текстовую раскадровку. Это инструмент насмотренности: в тексте видно структуру, которую видеоряд смазывает.

Два применения:
- **свой ролик** — проверить ритм и наглядность до публикации либо понять, почему результат вышел слабее ожиданий;
- **чужой ролик** — снять приёмы: длину хука, порядок блоков, частоту смены кадров, чем подкреплено каждое утверждение.

Приёмы копируем на уровне структуры, темы берём свои: пересъёмка чужого ролика теряет и охваты, и доверие.

## Workflow

1. **Получить файл.**
   ```bash
   yt-dlp -f mp4 "<url>" -o "<edit>/sources/%(id)s.mp4"   # для чужих роликов
   ```
   Свой ролик берём из `<videos_dir>/sources/` или из готового финала.

2. **Транскрипция** (кэш per-source, Hard Rule 9): агент вызывает
   `mcp__teletranscribe__transcribe_file_json /abs/path.mp4 speakers=1`, сохраняет raw в
   `<edit>/transcripts/_raw/<stem>.json`, затем
   `python helpers/transcribe_mcp.py --raw <raw>.json --out <edit>/transcripts/<stem>.json`.

3. **Границы кадров:**
   ```bash
   python helpers/scene_detect.py <video> --out <edit>/shots/<stem>.json
   ```

4. **Кадры и контактные листы:**
   ```bash
   python helpers/reel_breakdown.py --video <video> \
       --transcript <edit>/transcripts/<stem>.json \
       --shots <edit>/shots/<stem>.json \
       --frames-dir <edit>/breakdown/<stem> --sheet \
       --out <edit>/breakdown/<stem>.md
   ```
   Хелпер вырезает по кадру из середины каждого шота и собирает листы по 12 кадров с подписями «номер · тайминг».

5. **Описания кадров — смотрит сам агент.** Открой листы `_sheet_NN.png` и запиши по строке на кадр в `<frames-dir>/desc/shot_NNN.txt`: кто в кадре, крупность плана, что в руках, что написано на экране, монтажный эффект.

   Запасной путь для длинных роликов — `mcp__teletranscribe__describe_image_batch` со списком путей из `_pending_frames.json`. Замер 2026-09-16: 0,5 ₽ и 90–110 секунд на кадр, а модель выдумывает детали (в тесте появились несуществующий текст на экране и чужое имя). Проверяй такие описания по листам.

6. **Финальная таблица:** повторить шаг 4 с тем же `--frames-dir`, но без `--sheet` — хелпер читает `<frames-dir>/desc/shot_NNN.txt`, и правая колонка заполняется описаниями (без `--frames-dir` описания не подхватываются).

7. **Выводы.** Прочитать таблицу и метрики, затем ответить на четыре вопроса:
   - на чём держится хук и сколько он длится;
   - как устроено тело: список, метафора, история, челлендж;
   - чем подкреплено каждое утверждение — цифрой, предметом, скриншотом;
   - где сказано без показа (правая колонка повторяет «говорящая голова» подряд).

## Метрики и ориентиры

| Метрика | Ориентир | О чём говорит |
|---|---|---|
| Длина хука (до конца 3-го кадра) | 5–10 с | Долгий хук держится только на погружении |
| Кадров всего | 12–30 на ролик 50–70 с | Ниже — статика, выше — клип |
| Слов на кадр | ~10 | Длинные кадры годятся обзорам и таймлапсам |
| Медиана фразы | 8 слов, 80% ≤ 12 | Длинные предложения роняют досмотры |
| Смены плана в минуту | 15–25 | Считается по границам шотов |
| Ключевое слово на стыке | доля границ у начала слова | Показывает, попадает ли монтаж в речь |
| Кадры без показа | чем меньше, тем лучше | Кандидаты на вставку, скриншот, предмет |

Ориентиры получены на корпусе из 33 рилсов (`materials_private/reels_timochko/Raskadrovka_33_reels.md`) — там же эталонные раскадровки для сверки.

## Выход

`<edit>/breakdown/<stem>.md`:

```markdown
# Разбор: <имя ролика>

**Метрики:** 57,1 с · 24 кадра · 231 слово · 9,6 слов/кадр · хук 8,4 с · 23 смены/мин

| Тайминг | Текст | Кадр |
|---|---|---|
| 0.0–2.1 | За два года у моей жены было 700 дней выходных | крупный план у бассейна, женщина на лежаке |
| 2.1–4.0 | Когда мы только начинали встречаться | двое за столом, ноутбук закрывается |
```

## Правила

- **Чужие видео и их расшифровки держим в `materials_private/` или в `<edit>/`** — в публичный репозиторий они не идут.
- **Кэш транскриптов** (Hard Rule 9): повторный разбор того же файла обходится без новой транскрипции.
- **Копируем структуру, тему берём свою.** Разбор отвечает на вопрос «что здесь сработало», а дальше нужен свой хук, свой материал и свои примеры.
- Для оценки своего опубликованного ролика добавь к разбору статистику площадки: доля пропусков и среднее время просмотра показывают, хук слабый или тело провисает.
