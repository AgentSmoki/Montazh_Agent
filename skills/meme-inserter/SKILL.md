# meme-inserter

Вставляет мемы (видео-клипы и GIF) в ролик. По умолчанию — **по центру экрана** (Богдан просил не в угол), мем накладывается поверх твоего кадра, видео продолжает идти на фоне.

## Способы задать мем

**1. В сценарии — метка `[мем:...]`** (парсит `helpers/parse_meme_cues.py`):
- `[мем:🤯]` — по эмодзи (словарь `EMOJI_QUERIES` в `meme_fetch.py`, ~23 эмодзи)
- `[мем: confused math lady]` — текстовый запрос (любой)
- `[meme: mind blown]` — англ. синоним метки
- Модификаторы: `@3.5` (время появления, сек), `dur=2.0` (длительность), `full` (на весь экран вместо центра), `gif` (взять GIF вместо видео)
- Пример: `[мем:🤯 @12.5 dur=2.0]`

**2. Голосом в диалоге** — «вставь на 12-й секунде мем про взрыв мозга». Тогда агент сам зовёт `meme_fetch.py` с текстовым запросом и проставляет overlay в EDL. **Эмодзи подбирать не обязательно** — текстовый запрос работает всегда.

## ⚠️ Главный принцип подбора: по ЭМОЦИИ, не по контексту

Мем подбирается под **эмоцию, которую он должен вызвать у зрителя в этот момент**, а НЕ под то, что говорится/показано в кадре. «Пиши агент в комментарии» → искать не «comment»/«type» (контекст), а эмоцию финала: «хочу, забирай деньги» (`take my money`), «вау, так можно?!» (`mind blown`), «погнали, я в деле» (`lets go hyped`).

**Workflow подбора:**
1. Определить целевую эмоцию момента (хайп / вау-шок / «хочу» / смех / facepalm / триумф).
2. Под каждую эмоцию — свой эмоциональный запрос к KLIPY (не описательный).
3. **Показать пользователю 2-3 варианта кадрами ДО вставки** — мем субъективен, выбор за пользователем. Не вставлять вслепую.
4. После выбора — вставить по центру (`scale_w` 0.80).

Эмоция → запрос: хочу/продажа → `shut up take my money`; вау → `mind blown`; восторг → `excited lets go yes sir`; смех → `laughing hard`; недоверие → `really seriously`; триумф → `victory celebration`.

## Workflow

1. **Найти кандидатов** (не скачивая): `python helpers/meme_fetch.py "<запрос или эмодзи>" --edit-dir <edit> --list` — покажет топ-8 с размерами и URL. Выбрать подходящий по `--index N`.
2. **Скачать**: `python helpers/meme_fetch.py "🤯" --edit-dir <edit>` → `<edit>/memes/<hash>.mp4` + `<hash>.manifest.json` (Hard Rule #13).
3. **Из сценария разом**: `python helpers/parse_meme_cues.py scenario.md --edit-dir <edit> --apply edl.json` — найдёт все `[мем:...]`, скачает, допишет в `overlays` те, у кого указано `@T`. Без `@T` → вернёт в `unplaced`, время проставить вручную.
4. **Рендер** сам разместит: overlay с `position:"center"`, `scale_w:0.82` (82% ширины) кладётся по центру кадра (`render.py:build_final_composite`).

## Формат overlay-мема в EDL

```json
{"file": "memes/<hash>.mp4", "start_in_output": 12.5, "duration": 2.0,
 "position": "center", "scale_w": 0.82, "comment": "meme: 🤯 «Tim And Eric Mind Blown»"}
```
- `position`: `center` (default) | `topleft` (для `full` — на весь экран)
- `scale_w`: доля ширины кадра. 0.82 = мем 82% ширины по центру; 1.0 = во всю ширину.

## Провайдеры (заменяемые)

| Провайдер | Что даёт | Статус |
|---|---|---|
| **KLIPY** (default) | видео-клипы (`clips`, чистый mp4) + GIF (`gifs`) + стикеры. Бесплатно пожизненно, коммерция ок | ✅ ключ `KLIPY_API_KEY` |
| Vlipsy | HD video memes | ⏳ запрошен доступ (`docs/vlipsy_partnership_request.md`) |
| Tenor | GIF/mp4 | ⚠️ закрывается 30.06.2026 — не закладывать |

`memes` endpoint у KLIPY нет (Route not found) — видео-мемы ищем в `clips`, статичные в `gifs`. Если в `clips` пусто, `meme_fetch` сам падает в `gifs`.

Добавить нового провайдера: дописать функцию в `meme_fetch.py:PROVIDERS` + ключ в `.env`.

## Правила

- **Ключи — только из `.env`** (он в `.gitignore`). Никогда не хардкодить в EDL/коде.
- **manifest.json обязателен** на каждый скачанный мем (происхождение + checksum) — Hard Rule #13.
- **Кэш per-URL** (hash) — повторный запрос того же мема не качает заново.
- **Аудио мема не подмешивается** — reaction-мемы работают визуально, звук конфликтовал бы с голосом/музыкой. Если нужен звук мема — отдельная задача.
- **Лицензия:** KLIPY разрешает коммерческое использование. При смене провайдера — перепроверить права (важно, ролики для клиентов).
